## 🎮 Sobre el juego

**Doctor Palomo** es un top-down shooter 2D para móvil con estética gore anime. Encarnas al Doctor Palomo, un médico que tras ser mordido por una paloma radioactiva se convierte en una paloma con bata blanca, estetoscopio y muy mala leche.

A medida que avanza el juego, el tumor cerebral del Doctor Palomo empieza a hacer efecto: los controles se vuelven más caóticos, los movimientos más impredecibles, y la locura se apodera del personaje. Al estilo de Trevor en GTA V, el Doctor Palomo puede desencadenar una habilidad especial de furia total que multiplica el daño causado.

El objetivo es simple: sobrevivir al parque. Los enemigos, no tanto.

## 🚀 Cómo ejecutar el proyecto

### Requisitos
- [Godot Engine 4.x](https://godotengine.org/download)
- [Git](https://git-scm.com/)

### Pasos

```bash
# 1. Clonar el repositorio
git clone https://github.com/campaguille/VideoJuegoGODOT
cd VideoJuegoGODOT

# 2. Abrir Godot Engine
# 3. Importar el proyecto: seleccionar project.godot
# 4. Ejecutar con F5
```
